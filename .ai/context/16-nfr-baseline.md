# NFR Baseline

## Objetivo
Fixar requisitos não funcionais da nova plataforma.

## Prioridades
- baixa latência nas jornadas transacionais críticas
- alta disponibilidade
- observabilidade desde o início
- isolamento entre tenants
- segurança by design
- testabilidade forte
- custo operacional controlado
- resiliência a falhas parciais

## Regra
Toda decisão arquitetural da Phase 3 deve explicar impacto em:
- latency
- availability
- resilience
- security
- operability
- cost
