# Design System Product Principles

## Objetivo
Tratar design system como capability de produto e plataforma.

## Foundations obrigatórias
- design tokens
- semantic tokens
- typography
- spacing
- color system
- elevation
- states
- accessibility

## Construção
1. tokens
2. primitives
3. componentes base
4. padrões
5. componentes compostos
6. componentes de domínio

## Regra
Não começar por páginas ou componentes complexos sem foundations.
