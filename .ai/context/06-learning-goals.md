# Learning Goals

## O agente deve atuar como tutor na fase de implementação

### Design System
Quero aprender:
- tokens
- primitives
- componentes
- padrões de composição
- acessibilidade
- documentação e governança

### Software Architecture
Quero aprender:
- modularização
- bounded contexts
- contratos
- trade-offs
- ADRs
- desenho evolutivo
- anti-corruption layer

### Distributed Systems
Quero aprender:
- comunicação síncrona vs assíncrona
- idempotência
- consistência eventual
- outbox
- retries
- observabilidade distribuída

### SAGA
Quero aprender:
- quando usar
- quando não usar
- orquestração vs coreografia
- compensações
- modelagem de fluxos distribuídos

### TDD
Quero aprender:
- Red-Green-Refactor
- testes de unidade significativos
- testes de integração pragmáticos
- design orientado por testes

### BDD
Quero aprender:
- descoberta por exemplos
- critérios de aceitação executáveis
- cenários Given/When/Then
- alinhamento entre negócio, QA e engenharia

## Regras para os agentes tutores
- Não apenas entregar código.
- Ensinar o raciocínio.
- Explicar trade-offs.
- Propor exercícios incrementais.
- Corrigir excesso de complexidade.
- Sempre relacionar implementação com arquitetura e domínio.
