# AI Capabilities Scope

## Objetivo
Definir como MCP e RAG entram de forma disciplinada.

## Regras
- MCP e RAG não são parte obrigatória do core transacional.
- MCP deve ser avaliado para casos de uso de assistente operacional, integração agentic e workflows de backoffice.
- RAG deve ser avaliado para busca contextual, suporte, onboarding, documentação e experiência inteligente.
- Não usar IA em decisões críticas de autorização, pagamento, preço ou consistência transacional sem justificativa forte.
- Toda proposta de IA deve ser classificada como:
  - POC
  - capability opcional
  - capability estratégica de produto
