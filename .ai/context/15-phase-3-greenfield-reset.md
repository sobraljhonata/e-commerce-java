# Phase 3 Greenfield Reset

## Objetivo
A Phase 3 deve desenhar uma nova plataforma, sem reaproveitar código legado.

## Regras
- O legado é fonte de descoberta, não base de implementação.
- O novo produto deve ser projetado como plataforma comercial digital moderna.
- Não reproduzir limitações do legado sem justificativa.
- Não copiar o modelo de dados legado automaticamente.
- Toda decisão deve considerar:
  - latência
  - alta disponibilidade
  - testabilidade
  - segurança
  - observabilidade
  - custo operacional
  - escalabilidade
  - experiência de produto
